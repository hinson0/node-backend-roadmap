## 提交信息规则

请按照以下规范生成 Git 提交信息：

### 格式要求

- 使用简洁、明确的语言描述变更内容
- 控制在 50 字符以内，聚焦核心变更
- 使用中文描述

### 类型前缀

根据变更类型选择合适的前缀：

- `feat:` 新功能
- `fix:` 修复 Bug
- `docs:` 文档更新
- `style:` 代码格式调整（不影响逻辑）
- `refactor:` 重构代码
- `perf:` 性能优化
- `test:` 新增或修改测试
- `chore:` 构建/工具/依赖等杂项

### 示例

- `feat: 新增用户登录接口`
- `fix: 修复列表分页异常`
- `refactor: 优化数据查询逻辑`
- `docs: 更新 README 使用说明`
